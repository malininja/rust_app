# Feature: JWT Authentication + Role-Based Authorization

**Date:** 2026-03-13

## Purpose
Add stateless JWT-based authentication and role-based access control (RBAC) to the web service. All endpoints except `POST /auth/login` become protected. Read routes require any valid token; write routes require an admin role (code `"A"`).

## Approach

### State
Introduce `AppState { pool: PgPool, jwt_secret: String }` to carry both the DB pool and JWT secret through Axum's shared state. All routers become `Router<AppState>`.

### Auth flow
- `POST /auth/login` accepts `{ username, password }`, verifies the password with Argon2, looks up the user's role, and returns a signed JWT.
- JWT claims: `sub` (user UUID), `role` (role code), `exp` (1-hour expiry).
- Subsequent requests carry the token in the `Authorization: Bearer <token>` header.

### Middleware approach
Rather than a middleware layer, `Claims` implements `FromRequestParts<AppState>` so it can be extracted directly in handler signatures. Handlers that need a role check do so manually at the top of the function body.

### RBAC rules
| Role | Allowed routes |
|---|---|
| Any valid token | GET routes (read-only) |
| Admin (`"A"`) | All routes including POST/PATCH/DELETE |

## New module: `src/auth/`
- `claims.rs` — `Claims` struct + `FromRequestParts` extractor
- `auth_errors.rs` — `AuthError` enum via `thiserror`
- `auth_service.rs` — `login()` business logic
- `auth_handler.rs` — Axum handler for `POST /auth/login`
- `auth_router.rs` — registers the login route
- `dtos/` — `LoginRequestDto`, `LoginResponseDto`

## Key Rust Concepts
- **Shared state with Axum**: `Router::with_state`, `State<T>` extractor
- **`FromRequestParts`**: implementing a custom extractor on an async trait (no `#[async_trait]` needed in edition 2024)
- **`jsonwebtoken` crate**: `encode`/`decode`, `EncodingKey`/`DecodingKey`, `Claims`, `Validation::new(Algorithm::HS256)`
- **Argon2 password verification**: `PasswordHash::new(&stored)` then `Argon2::default().verify_password()`
- **`thiserror`**: deriving `Error` for structured error enums
