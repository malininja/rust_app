# Feature: Hello World API Service

**Date:** 2026-02-21
**Status:** In progress — user implementing

---

## Purpose

Build a minimal Rust HTTP API service with a single endpoint:

```
GET / → "Hello world"
```

This serves as the foundational starting point for the Rust learning project.

---

## Approach

**Framework:** Axum
**Async runtime:** Tokio (with `full` feature flag)

Axum was chosen for its:
- Ergonomic, type-safe routing API
- Strong ecosystem alignment (built on Tokio + Hyper)
- Beginner-friendly documentation with a "Hello, World!" example at the top of the crate docs

---

## Implementation Steps (User-driven)

1. `cargo init` — initialize the Cargo project
2. Add `axum` and `tokio` (with `features = ["full"]`) to `[dependencies]` in `Cargo.toml`
3. Write an async handler function returning `&'static str`
4. Wire a `Router` with `.route("/", get(handler))`
5. Bind to a port and `.serve()` the router
6. Verify with `cargo run` and `curl http://localhost:3000/`

---

## Key Rust Concepts

- **`async fn` / `.await`** — Axum handlers are async; the runtime drives them to completion
- **`#[tokio::main]`** — macro that bootstraps the Tokio runtime for `async fn main()`
- **`IntoResponse` trait** — Axum's abstraction for anything that can become an HTTP response; plain `&'static str` implements it automatically
- **Cargo feature flags** — optional crate functionality declared as `{ version = "...", features = ["full"] }`
- **`axum::Router`** — type-safe route-to-handler mapping
